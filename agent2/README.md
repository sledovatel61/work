На основе свежих разборов трендов (берёзовский блог, sostav.ru, vc.ru, РБК, bonnieandslide) для ниши инжиниринг/строительство/девелопмент вырисовывается устойчивый набор приёмов:

| Тренд | Как применяем в нашей презентации |
|---|---|
| **Тёмная тема** (графит / ночной синий / угольный) | Базовый фон всех слайдов. Тёмный = премиум + технологичность (как у Tesla/SpaceX). |
| **Неоновые/яркие акценты** (оранж, бирюза, золото) | Один сигнальный акцент (оранж) + вторичный (бирюза) — только на метриках, линиях, ключевых словах. |

| **Bento-сетки / модульные карточки** | Структура Группы и компетенции раскладываются по прямоугольным ячейкам. |
| **Инфографика вместо «простыней»** | Метрики (м³, т, п.м., этажи) — крупными блоками-числами, не таблицами. |
| **Изометрия и 3D-элементы** | Схемы структуры и инфраструктуры — лёгкая изометрия, тонкий wireframe. |
| **Многослойные градиенты** | Мягкий переход графит → глубокий синий, «подсветка» углов неоновым свечением. |
| **Антитренды (чего избегаем)** | Объёмные 3D-диаграммы с тенями, клипарт, стоковые «стройплощадки» с солнцем, пафосные буллеты. |

**Вывод:** берём «тёмный хай-тек минимализм» — графитово-синий фон, один неоновый акцент, крупная типографика, изометрия и Bento-сетки. Это одновременно премиально (B2B-аудитория девелоперов/госзаказчиков) и технологично (инжиниринг, космос, метро).

## 2. Цветовая палитра (HEX)

Премиум-база «глубокий синий + графит», сигнальный акцент «оранж» (ассоциация со стройкой/энергией/предупреждающими жилетами), вторичный «бирюза» (технологии, точность, вода/тоннели), деликатное «золото» для премиальных микро-акцентов.

| Роль | Название | HEX | Применение |
|---|---|---|---|
| Фон основной | **Графит** | `#0A0E14` | Фон всех слайдов |
| Фон вторичный | **Глубокий синий** | `#0E1B2E` | Градиент, подложки |
| Поверхности | **Синяя сталь** | `#16263C` | Карточки, панели, чипы |
| Акцент №1 | **Сигнальный оранж** | `#FF6B00` | Метрики, ключевые слова, линии, CTA |
| Акцент №2 | **Техно-бирюза** | `#22D3EE` | Схемы, иконки, вторичные метрики |
| Премиум-акцент | **Золото** | `#D4AF37` | Микро-акценты, разделители (дозированно) |
| Текст основной | **Белый лёд** | `#E8EDF2` | Заголовки, основной текст |
| Текст вторичный | **Серый графит** | `#8A97A8` | Подписи, пояснения |

**Правило 80/20:** 80% поверхности — тёмные тона, 20% — акценты. Оранж — только один элемент на слайд (чтобы «выстреливал»), бирюза — поддержка.

## 3. Типографика

Все шрифты с полной поддержкой кириллицы (обязательное условие — русский язык):

| Роль | Шрифт | Характер | Кегль/приём |
|---|---|---|---|
| **Заголовки / display** | **Unbounded** (variable) | Геометрический гротеск, широкая посадка, «техно» | 48–96 pt, UPPERCASE для титула, межбуквенный интервал −2% |
| **Текст / body** | **Inter** | Нейтральный, читаемый sans | 16–20 pt, интерлиньяж 130–140% |
| **Цифры / метрики / тех.подписи** | **IBM Plex Mono** | Моноширинный, «инженерный» | Числа 64–120 pt, табулярные цифры; подписи/коды 12–14 pt |

Альтернативы (если нет лицензии): `Golos Text` (вместо Unbounded), `Manrope` (вместо Inter).

**Правила:**
- Один слайд — одна мысль, вывод в заголовке.
- Цифры метрик — крупнее всего остального (они и есть «герой»).
- Минимум текста: короткие строки, не более 5–7 слов в строке.

## 4. Общий визуальный стиль

**Название концепта: «Тёмная инженерия» (Dark Engineering).**

- **Минимализм** — много «воздуха», одна фокусная зона на слайд.
- **Технологичность** — тонкие линии-wireframe, blueprint-сетка 1px, угловые маркеры, координатные подписи в стиле чертежа.
- **Архитектурная чёткость** — жёсткая 12-колоночная сетка, выравнивание по невидимым направляющим, прямоугольные модули без скруглений (или скругление 4px).
- **Фирменный паттерн** — «инженерная сетка»: едва заметная изометрическая сетка + точки-узлы на пересечениях (отсылка к чертежам и генплану).
- **Свечение (glow)** — мягкое неоновое свечение акцентных линий и цифр (оранж/бирюза), без перебора.
- **Единый модуль** — все слайды делятся на одинаковые зоны: шапка (логотип + номер слайда), тело (контент), подвал (дескриптор группы).

## 5. Послайдовое визуальное решение

### Слайд 1 — Титульный
**Фон:** сгенерированное изображение `img/slide1_cover_bg.png` — графитово-синий градиент, blueprint-сетка, силуэт высотной башни (отсылка к НКЦ, 288 м) с тонкими орбитальными кольцами, неоновые оранж/бирюза линии.
**Композиция:** логотип группы — верхний левый угол (12-колоночная сетка); по центру — название группы (Unbounded, 72–96 pt, белый, UPPERCASE) + слоган под ним (Inter 20 pt, серый `#8A97A8`); нижняя треть — строка-дескриптор «Инженерный холдинг · Москва» и 3 логотипа компаний в один ряд.
**Акцент:** слово-ключ в названии (например, `UNIT` или подчёркивающий штрих) — оранж `#FF6B00`; тонкая горизонтальная линия-разделитель с бирюзовым свечением.

### Слайд 2 — Группа компаний (структура)
**Фон:** тёмный градиент `#0A0E14 → #0E1B2E` + паттерн-сетка.
**Композиция:** Bento-сетка / изометрическая схема (`img/group_structure.png` как основа): вверху центральный хаб — «Управляющая компания ЮНИТ ИНЖИНИРИНГ»; ниже три блока — ЮНИТ ИНЖИНИРИНГ (инжиниринг), АММ-СТРОЙ (генподряд/СМР), МОСТЫ И ТОННЕЛИ (спец. инфраструктура). Связи — тонкие неоновые линии с узлами.
**Цвет блоков:** у каждого блока своя роль — подпись цветом (оранж = управление, бирюза = стройка, золото = спецработы). Под каждым блоком — 2–3 ключевые метки компетенций.
**Приём:** цифры-маркеры (год, ИНН-лайт, «10+ лет») как тех.подписи в стиле чертежа.

### Слайд 3 — Компетенции
**Фон:** тёмный + изометрия-подложка.
**Композиция:** сетка 3×3 (или 2×4) карточек-пиктограмм: Демонтаж, Отделка, Инженерные системы, Гидроизоляция, Монолит, Буровые работы, Мосты/тоннели/метро, Столярные/монтажные, Сантехника/электрика.
**Подача:** тонкие линейные иконки (stroke 1.5px) в бирюзе `#22D3EE`, активная карточка — подсвечена оранжем. Под каждой иконкой — короткое название. Метрики-акценты крупно: `20 000 м³` бетона, `291` БКС, `1000 т` испытаний.
**Приём:** иконки — в едином геометрическом стиле (квадрат/окружность на изометрической подложке), без фотографий.

### Слайд 4 — Проекты
**Фон:** тёмный, слева — инфраструктурная изометрия `img/infrastructure_isometric.png` (тоннель, метро, мост, кран, башня) как декоративный слой с низкой непрозрачностью.
**Композиция:** Bento-сетка из «карточек-проектов» (5–6 ячеек): НКЦ (башня 288 м), Кленовый бульвар (20 000 м³), Говорово, Академическая/Троицкая линия, тоннель Видное, Мичуринский проспект (БНС + испытания 1000 т).
**Подача:** каждая карточка = название проекта + 1–2 метрики крупно + мини-иконка типа объекта (метро/мост/тоннель/здание). Сетка 2×3, акцентная (самая большая) ячейка — НКЦ (флагман).
**Приём:** карточки — прямоугольные плитки с тонкой рамкой `#16263C`, при наведении/фокусе — свечение оранжем.

### Слайд 5 — Контакты (финал)
**Фон:** `img/contacts_bg.png` — минималистичная геометрия, неоновая оранжевая линия-горизонт, сходящиеся wireframe-линии.
**Композиция:** центр — название группы + слоган (финальный CTA-месседж); ниже — три колонки контактов по компаниям (телефон, e-mail, сайт, адрес) в формате моноширинного текста (IBM Plex Mono) как «реквизиты на чертеже».
**Акцент:** CTA-кнопка/строка оранжем: «Запросить коммерческое предложение» или телефон крупно. Внизу — ИНН/ОГРН мелко (тех.подпись).
**Приём:** минимум графики, максимум воздуха — финальная «точка» истории.

## 8. Рекомендации по сборке (для дизайнера/верстальщика)

- **Формат:** 16:9 (1920×1080), экспорт в PDF + PPTX.
- **Инструменты:** Figma (основной макет) → PowerPoint/Keynote для финальной анимации.
- **Анимация:** мягкие fade/slide, «подсветка» акцентных линий и цифр, без перегруза.
- **Сетка:** 12 колонок, отступы 60px по бокам, 40px сверху/снизу.
- **Иконки:** единый набор (stroke 1.5px, закругление концов), цвет — бирюза, hover/актив — оранж.
- **Логотип группы:** «UNIT» в Unbounded Bold, с неоновой оранжевой точкой/штрихом-маркером; под ним — «Инженерная группа» мелко.
