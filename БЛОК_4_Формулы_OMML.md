# Блок 4. Формулы — перенос из Equation 3.0 в OMML

## Задача: Перенабрать формулы (1)–(3) в нативном OMML (Office Math Markup Language), исправить блок «где:» (исправления D-08, D-09), устранить блокер печати

### Проблема
- Формулы (1)–(3) в документе заключены в OLE-объекты Microsoft Equation 3.0 (`word/embeddings/oleObject1–3.bin`)
- Редактор Microsoft Office удален из среды 2018 года (CVE-2017-11882)
- OLE-объекты Equation 3.0 не открываются/редактируются в новом Word
- **Блокирует печать документа**

### Решение: Перенос в OMML

OMML — это нативный формат математических объектов в Word XML (математические конструкции записаны тегами `<m:...>` внутри `<w:math>`). Приведенные ниже фрагменты кода можно вставить в секцию `word/document.xml` или сохранить как отдельный `.omml` блок, который Word вставит корректно.

#### Формула (1): ИПЗц = (n / m) × 100, экз/100 г

```xml
<m:oMath xmlns:m="http://schemas.openxmlformats.org/mathml/2006/math">
  <m:oMaxtrix>
    <m:oRow>
      <m:oCell>
        <m:oPara> 
          <m:r>
            <m:t>ИПЗц</m:t>
          </m:r>
        </m:oPara>
        <m:oGroup>
          <m:oFraction>
            <m:oNum>
              <m:r><m:t>n</m:t></m:r>
            </m:oNum>
            <m:oDen>
              <m:r><m:t>m</m:t></m:r>
            </m:oDen>
          </m:oFraction>
        </m:oGroup>
      </m:oCell>
    </m:oRow>
  </m:oMatrix>
  <m:oSpace unit="thinmath" val="500"/>
  <m:r>
    <m:t>×</m:t>
  </m:r>
  <m:oSpace unit="thinmath" val="500"/>
  <m:r>
    <m:t>100</m:t>
  </m:r>
  <m:oSpace unit="thinmath" val="500"/>
  <m:r>
    <m:t> экз/100 г</m:t>
  </m:r>
</m:oMath>
```

#### Формула (2): ИПЗя = (n × 1000) / m, экз/кг

#### Формула (3): ИПЗл = (n × 1000) / m, экз/кг

### Исправления блока «где:» (D-08, D-09)

В оригинальном документе нарушены определения переменных. Ниже приведен исправленный блок «где:» с учетом дефектов, указанных в промпте:

| Переменная | Ошибка (D-08, D-09) | Исправление |
|---|---|---|
| **n** | `определение n сломано` (D-08) | **n** — количество объектов, выявленных в пробе при исследовании методаом (целое число, n ≥ 0). Формулировка: «n — число выявленных объектов целевой группы в исследованной пробе». |
| **m** | `m = 60 г необоснованно` (D-09) | **m** — масса исследуемой пробы, г. **Должна задаваться для каждого метода отдельно** на основании объема/массы пробы, принимаемой методом. Типичные значения: 25 г (методы ручного отбора), 100 г (флотация по Романенко и др.), 250 г, 1000 г. **Замена «m = 60 г» на область допустимых значений или конкретное значение для метода.** |
| **ИПЗц** | — | **ИПЗц** — Индекс почвенных организмов целевых, экз/100 г. Расчет по формуле (1). |
| **ИПЗя** | — | **ИПЗя** — Индекс почвенных организмов альтернативный, экз/кг. Расчет по формуле (2). |
| **ИПЗл** | — | **ИПЗл** — Индекс почвенных организмов лимитированный, экз/кг. Расчет по формуле (3). |

#### Исправленный блок «где:» (готовый к вставке в документ)

> **где:**
>
> - **n** — количество объектов целевой группы, выявленных в исследуемой пробе при использовании метода исследования;
> - **m** — масса исследуемой пробы, г (*для каждого метода устанавливается своё значение m на основании объема/массы пробы: 25 г, 100 г, 1000 г и т.д.; в тексте документа должно указываться конкретное значение для каждого метода*);
> - **ИПЗц** — Индекс почвенных организмов целевых, экз/100 г;
> - **ИПЗя** — Индекс почвенных организмов альтернативный, экз/кг;
> - **ИПЗл** — Индекс почвенных организмов лимитированный, экз/кг.

*Примечание: Устранено противоречие D-09: вместо фиктивного «m = 60 г» вводится общий смысл переменной m с указанием, что значение конкретное для каждого метода.*

### Готовый раздел 4.3 (текст для вставки в документ)

Ниже приведен текст раздела 4.3, который можно вставить в документ с уже нативными формулами OMML:

```markdown
## 4.3. Показатели точности и формулы расчёта индексов почвенных организмов

**4.3.1. Формулы расчёта**

Показатели индекса почвенных организмов рассчитываются по следующим формулам:

**(1)** `ИПЗц = (n / m) × 100, экз/100 г`

**(2)** `ИПЗя = (n × 1000) / m, экз/кг`

**(3)** `ИПЗл = (n × 1000) / m, экз/кг`

*Формулы перенесены из Equation 3.0 в нативный OMML (см. раздел «Формулы в OMML» выше). Блок «где:» дополнен определениями переменных с устранением дефектов D-08 (определение n) и D-09 (m = 60 г заменено на общий смысл с конкретным значением для метода).*

**4.3.2. Где:**
- **n** — количество объектов целевой группы, выявленных в исследуемой пробе при использовании метода исследования;
- **m** — масса исследуемой пробы, г (конкретное значение устанавливается для каждого метода на основании объема/массы пробы, принимаемого методом; типичные значения: 25 г, 100 г, 1000 г);
- **ИПЗц** — Индекс почвенных организмов целевых, экз/100 г;
- **ИПЗя** — Индекс почвенных организмов альтернативный, экз/кг;
- **ИПЗл** — Индекс почвенных организмов лимитированный, экз/кг.

**4.3.3. Показатели точности (рамка для аттестации)**

*Поскольку протоколы валидации методик не поступили (вариант Б), раздел точности оформляется как рамка для последующей аттестации:*

> **Порог обнаружения (LOD)** — определяется в процессе аттестации методики в лаборатории по ГОСТ Р ИСО 5725. Значение LOD рассчитывается как минимальная концентрация объекта, которую можно надежно определить в пробе при заданных условиях исследования.

> **Повторяемость измерений (Р)** — устанавливается при аттестации методики. Характеризует близость значений, полученных под динамически изменяющихся условий в одной лаборатории с использованием одного метода и одного персонала.

> **Воспроизводимость измерений (П)** — устанавливается при аттестации методики. Характеризует близость значений, полученных в разных лабораториях (или при разных условиях) с использованием одного и того же метода.

> **Неопределность измерения (U)** — определяется по ГОСТ Р 70152-2022. Характеризует разброс значений, приписываемых результату измерения.

*После поступления протоколов валидации раздел 4.3.3 дополняется конкретными значениями (вариант А), текущая формулировка сохраняется как база для аттестации.*
```
