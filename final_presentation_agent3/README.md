# UNIT GROUP — финальная презентация (вариант агента 3)

**Файлы для использования:**
- **`UNIT_GROUP_Презентация.pdf`** — 5 слайдов, 16:9 (13,33″×7,5″), готов к отправке/печати
- **`UNIT_GROUP_Презентация.pptx`** — те же 5 слайдов для PowerPoint (пиксельно идентичны PDF)

Исходники: `build_unit_group.py` (Python/Pillow — правится и пересобирается за минуту), `img/` — сгенерированные изображения, `fonts/` — шрифты (OFL, свободные), `slides/` — PNG-слайды 2400×1350.

---

## Чем отличается от версии оркестратора (`arena/01a01ff7-work-v3-final`)

| Параметр | Оркестратор | Эта версия |
|---|---|---|
| Основной текст | 10–13 px (мелко) | **21–30 px** (в ~2,2 раза крупнее) |
| Заголовки | 22–48 px | **92–116 px** (Unbounded ExtraBold) |
| Цифры-метрики | 24–38 px | **44–62 px** (IBM Plex Mono Bold) |
| Объём текста | максимум фактуры | сокращён на ~30% — «громкий минимализм» |
| Слайды 2–3 | текстовые списки | карточки + фото собственного парка/объектов |

Типографика: тело 24–30 px на канвасе 2400 px ≈ **11–12 pt на печатном листе А4-альбом** — комфортно читается с расстояния 1,5–2 м и при печати без масштабирования.

## Структура (5 слайдов)

1. **Титул** — «Полный цикл. Одна ответственность.» + 4 ключевые цифры (3 компании · 10+ лет · 288 м · 24/7)
2. **Структура группы** — три карточки компаний + лента «Один тендер → один договор → одна ответственность»
3. **Компетенции** — конвейер 6 этапов (проект → сваи → монолит → гидроизоляция → инженерия → отделка) + собственный парк (Casagrande, Hilti) + 3 цифры-доказательства (291 БКС · 1 000 т · 20 000 м³)
4. **Проекты** — флагман НКЦ (288 м / 257 000 м² / 20 000 раб. мест) + метро, тоннели, геотехника, ТПУ
5. **Контакты** — полные реквизиты трёх компаний, CTA

## Проверенные факты (веб-верификация, агент 3)

- **НКЦ**: открыт 13.09.2025; башня 288 м / 47 этажей; площадь 257 000 м² (арх. бюро UNK); ~20 000 рабочих мест. Формулировка на слайде — «комплекс работ на объекте», т.к. публично генподрядчиком назван «Мосинжпроект» (kommersant.ru, unkproject.com, Wikipedia).
- **«Кленовый бульвар» (БКЛ)**: рекордный котлован 644 м, наша доля — сооружение основных конструкций 20 000 м³ (буклет ООО «Мосты и тоннели»; по объекту в целом >90 000 м³ — nashtransport.ru).
- **«Академическая» (Троицкая линия)**: участок «ЗИЛ—Новаторская» открыт 13.09.2025 (stroi.mos.ru, Wikipedia).
- **Тоннель в Видном**: ~300 м, трасса «ЮЛА» — концессия 86,7 млрд ₽ (archi.ru, gazetabiznes.ru).
- **Говорово/Столбово**: открыты 30.08.2018 (Солнцевская линия).
- **Новокутузовский тоннель ТТК**: capремонт 2022–2023 без полного закрытия движения (interfax.ru, mos.ru).
- **ОГРН ЮНИТ ИНЖИНИРИНГ**: указан **1257700109072** по данным ЕГРЮЛ (rusprofile.ru, ИНН 9701308826, рег. 07.03.2025). В исходном PDF компании указан ОГРН 1227700257905 — **рекомендуется сверить с свежей выпиской** и при расхождении заменить (одно значение в `build_unit_group.py`, строка с `1257700109072`).
- **АММ-СТРОЙ**: зарегистрирована 04.05.2026 (выписка ЕГРЮЛ в репо) — подана как операционный контур с командой и портфелем AIVA СТРОЙ, без заявлений об «опыте компании».

## Изображения

Все изображения в `img/` — **сгенерированы ИИ** (не фотографии реальных объектов). Для юридической чистоты при внешнем использовании можно заменить на фото объектов из буклета ООО «Мосты и тоннели».

## Пересборка

```bash
pip install pillow python-pptx
python3 build_unit_group.py
```

Шрифты (Unbounded, Inter, IBM Plex Mono — SIL OFL) лежат в `fonts/` и подключаются локально.

4. **Слайд 2**: добавлен фоновый панорамный кадр города со стройкранами (генерация v2, bg_city2).
5. **Слайд 3**: буровая установка показывается **целиком** (contain-fit без обрезки + размытая подложка), яркость поднята.
